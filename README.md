# Founding Five

A company run by five Claude Code agents (research, publications, product, data & growth, ops), coordinated through a shared brief and a daily status file.

## Layout

```
.claude/
  agents/          # the five lead agents
  skills/          # repeatable playbooks (paper format, launch checklist, scan-anonymize)
CLAUDE.md          # company brief: product, launch date, rules, who approves what
STATUS.md          # Done / Next / Blocked per agent, updated daily
research/ papers/ product/ data/ gtm/ ops/
```
